The Project

A student portal that teaches, tests, and tracks

Built for ALT School as a front-end engineering capstone, then carried past the brief onto a real Supabase backend — one app, from the browser down to the database.

Learn

Video, article, and assignment lessons across a real front-end-development curriculum.

Assess

A nine-type quiz engine that grades itself and gives instant, per-question feedback.

Track

Per-student progress, bookmarked notes, and a downloadable resource hub.

Authentication

Real accounts, real sessions

Sign up

Email, password, name — via Supabase Auth

→

DB trigger

Auto-creates the matching profile row

→

Sign in

Session tracked app-wide via context

→

Route guard

Signed-out visits redirect to /login

No page in the app renders for a signed-out visitor — every route sits behind a single RequireAuth wrapper.

Back End

One Postgres schema, two kinds of table

Catalog — shared, read-only

courses → modules → lessons quizzes → questions (payload jsonb) resources

Nine question types, one payload column — matching tables instead of ~15 sparse ones.

Personal — private, per student

profiles notes lesson_progress course_progress quiz_attempts

One row per student, per table — never visible to another student.
